# Inamdar Captain — Waiter Ordering Mobile PWA

High-performance mobile Progressive Web Application (PWA) tailored for restaurant captains and floor waiters.

## Features
- **Compact Mobile Grid:** Space-efficient floor layout with quick 3-column / 2-column view switcher.
- **Table Management:** Real-time table occupancy, quick PAX selector, section filtering (`AC`, `FAMILY AC`, `PARCEL`, `HOME DELIVERY`).
- **Speed Ordering:** Instant category filtering, real-time dish search, course grouping, customizable prep notes.
- **KOT Firing:** One-tap order dispatch directly synced with Kitchen Display System (KDS) via Supabase Realtime.
- **Kitchen Alerts:** Real-time audio and visual chimes when food is marked ready in the kitchen.
- **Theme Support:** One-tap toggle between Day Mode (high-contrast light) and Night Mode (dark).

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
